# RF-Air-Quality-Forecasting
This is an end to end data science project that answers why random forest regression is the right model for forecasting air quality. It takes 5 years of PM2.5 concentration data from the UC Irvine Machine Learning Repository and trains and tests a random forest regression model (first four years are training data) on said data. It then runs this model alongside a multiple linear regression model to see how their predictive power compares across different time lags. 

I wrote an in depth report about the math behind the random forest algorithm here: https://github.com/Timothyconsidine/RF-Air-Quality-Forecasting/blob/main/Machine_Learning_Project_Timothy_Considine.pdf
